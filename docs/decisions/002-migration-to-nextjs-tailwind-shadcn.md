# 002: Migration to Next.js, Tailwind CSS, and shadcn/ui

Status: Approved

Context
- The initial static site is simple, but we need better scalability, component management, and styling efficiency.
- Next.js provides a robust foundation, Tailwind CSS streamlines styling, and shadcn/ui offers high-quality, customizable components.

Decision
- Migrate the project from static HTML/CSS/JS to Next.js (App Router), Tailwind CSS, and shadcn/ui.

Consequences
- Requires a build step (Node.js).
- Modern component-based architecture.
- Increased initial complexity but better long-term maintainability.
- Faster development speed for UI components.
